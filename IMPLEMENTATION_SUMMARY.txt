ALGORITHMS IMPLEMENTED:
  1. Lloyd's K-Means Clustering
     - Feature normalization (min-max scaling)
     - Distance metric: L2 (Euclidean)
     - Convergence detection
     - WCSS calculation for elbow method

  2. Principal Component Analysis (PCA)
     - Covariance matrix calculation
     - Power iteration for eigenvalue extraction
     - Data projection onto principal components
     - Dimensionality reduction (5D → 2D)

  3. Logistic Regression
     - Sigmoid activation function
     - Binary cross-entropy loss
     - Gradient descent optimization
     - Feature-wise coefficient calculation

  4. RFM Segmentation
     - Quartile-based ranking (1-4 per dimension)
     - Composite score formula: R*100 + F*10 + M
     - Segment classification (7 categories)
     - Business rule thresholds
